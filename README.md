# 紫微斗数排盘

macOS 上的紫微斗数命盘工具。输入生辰，排出十二宫、十四主星、六吉六煞、四化、大限。

排盘逻辑经过 **80 组随机案例**与开源库 iztro 交叉验证，结果逐宫一致。

## 下载

到 [Releases](../../releases) 页面下载最新版 **Ziwei-1.0.zip**，解压后把
`Ziwei.app` 拖进「应用程序」文件夹。

首次启动 macOS 会拦截（个人开发者没有 $99/年的 Apple 公证）：右键点
app 图标 →「打开」→ 在弹窗里再点一次「打开」即可，之后照常启动。
也可以终端里跑一次 `xattr -cr /Applications/Ziwei.app` 永久放行。

- 系统要求：macOS 14.0+，**Apple Silicon**（M 系列芯片）

## 用法

左侧选性别、历法、生日、时辰，右侧命盘实时更新。

- **历法**可切公历 / 农历。农历输入会自动反查对应的公历日期
- **时辰**有 13 个选项：早子时、丑时……亥时、晚子时
- **用此刻**直接排当前时间
- 命宫格子金色高亮，带「身」标记的是身宫
- 每宫底部是**大限岁数**，主星右上角的「禄权科忌」是生年四化

## 排盘依据

| 项目 | 取法 |
|---|---|
| 农历换算 | 系统 `Calendar(identifier: .chinese)`（ICU 天文数据），不自己维护农历表 |
| 命宫 | 寅起正月顺数至生月，再起子时逆数至生时 |
| 身宫 | 同起点，子时顺数至生时 |
| 五行局 | 命宫干支纳音 → 水二 / 木三 / 金四 / 土五 / 火六 |
| 紫微星 | 借数法：商 = ⌈日 ÷ 局⌉，借 = 商×局 − 日；从寅顺数商位，借数偶则顺行借位、奇则逆行借位 |
| 天府 | 与紫微以寅申为轴对称 |
| 大限 | 阳男阴女顺行（命→父母→福德），阴男阳女逆行（命→兄弟→夫妻）；起运岁 = 局数 |
| 庚干四化 | 太阳禄、武曲权、太阴科、天同忌（中州派） |

### 有争议的三处，本作的取舍

1. **晚子时**（23:00–23:59）：按次日排。命盘上会显示次日日期
2. **闰月**：按本月算，不做「闰月分半」
3. **庚干四化**：取中州派「太阳武曲太阴天同」。紫云派作「太阳武曲天府天同」，若需可在 `Core.swift` 的 `sihua` 表里改一行

## 怎么验证的

命理软件排错一个宫位就废了，所以不敢只靠手算。

做法是用 Node 装开源库 `iztro`，同一个生日两边各排一次，逐宫比对宫名、主星（含四化）、大限。

```
60 组随机日期（1925–2025，男女各半，12 个时辰）
→ 60 通过，0 失败

20 组晚子时（23:00）
→ 20 通过，0 失败
```

比对脚本思路：本作 `./Ziwei 1990 1 1 10 M` 输出文本盘，iztro 侧用
`astro.bySolar(date, timeIndex, gender, false, 'zh-CN')` 输出同构文本，按地支为键 diff。

### 交叉验证抓出来的两个 bug

1. **宫干算错**。从寅宫推到任意宫位时，天干偏移用了 `(branch - 2)` 没先 mod 12。
   寅→子是 10 格，写成 -2 格，导致**子宫和丑宫的天干全反**。而五行局由命宫干支的纳音决定，
   所以这个错会连锁把紫微位置、整盘星曜全带偏。1988-1-7 晚子时那例：本作算出庚子/土五局，
   实际应为壬子/木三局。
2. **大限方向反了**。原本以为「顺行」是沿宫位顺序（命→兄弟→夫妻），
   实际术语里顺行指地支顺时针，即命→父母→福德。查证后改正。

## 界面实现里的坑

- **命盘不居中**。十二宫全部用 `.offset()` 定位，而 offset 不参与布局计算，
  于是 ZStack 的固有尺寸只有一格大，外层 `.frame(width:height:)` 把这一格居中到整块区域，
  整个盘就偏了。解法是先塞一个 `Color.clear.frame(width: side, height: side)` 当占位。
- **`@State` 用不了**（Command Line Tools 没带 SwiftUIMacros 插件），
  所有状态放进 `AppModel: ObservableObject`，用 `@StateObject` 持有。
- **离屏截图**：`ImageRenderer` 画不出 AppKit 控件，`TextField` / `Menu` 会变成黄色禁止符号。
  加了个 `RenderConfig.isRendering` 开关，渲染时换成纯 `Text`。

## 离线出图

屏幕锁着也能验证界面：

```bash
./Ziwei --render out.png 1990 1 1 10 M
```

不需要窗口、不需要屏幕录制权限。

## 命令行排盘

```bash
./Ziwei 1990 1 1 10 M          # 公历
./Ziwei 1990 1 1 10 M --lunar  # 农历输入
```

输出十二宫的干支、宫名、大限、主星、辅星。

## 编译

```bash
SDK=$(xcrun --show-sdk-path)
swiftc -sdk "$SDK" -target arm64-apple-macos14.0 -parse-as-library -O Core.swift main.swift -o Ziwei
```

`-parse-as-library` 不能省。多文件时顶层代码必须在 `main.swift` 里。

图标：

```bash
swiftc -O makeicon.swift -o makeicon && ./makeicon && iconutil -c icns Ziwei.iconset -o Ziwei.icns
```

## 说明

本工具只做**排盘**，不做吉凶推断。星曜位置、四化、大限是确定的计算；
至于「这个盘代表什么」，不同流派说法差异很大，软件不替你下结论。
